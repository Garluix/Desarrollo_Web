Investigación del Proyecto

Documentación técnica, arquitectura web y fundamentos de Bootstrap 5

1. ¿Qué es Bootstrap?

Es el framework frontend de código abierto más utilizado para el desarrollo web ágil y adaptativo. Proporciona una base sólida de estilos predefinidos, componentes interactivos y un sistema de disposición flexible.

Bootstrap 5: Trabaja sobre JavaScript nativo sin dependencias de jQuery y aprovecha variables CSS nativas para mayor velocidad.

2. Ventajas del Framework CSS

  • Velocidad de entrega: Permite construir maquetas y vistas funcionales en una fracción del tiempo habitual.
  • Estandarización: Alinea a todos los desarrolladores bajo la misma nomenclatura de clases y estructura.
  • Compatibilidad: Hojas de estilo de normalización (Reboot) que eliminan diferencias entre navegadores.
  • Mantenimiento: Facilita correcciones globales y escalabilidad modular.

3.Diseño Responsivo

Es la técnica de estructuración web que adapta de forma automática el contenido y los elementos visuales según las dimensiones de la pantalla. Bootstrap implementa un enfoque Mobile-First, diseñando primero para teléfonos y expandiendo la vista progresivamente.

xs < 576px sm ≥ 576px md ≥ 768px lg ≥ 992px xl ≥ 1200px xxl ≥ 1400px

4. Sistema de Grillas (Grid System de 12 Columnas)

La distribución espacial funciona mediante tres capas jerárquicas directas:

.container
Contenedor

Enmarca el área de trabajo, define anchos máximos responsivos y centra el contenido en pantalla.

.row
Fila (Flexbox)

Actúa como fila horizontal que agrupa las columnas y compensa el padding lateral.

.col-*
Columnas

Define cuánto espacio ocupa cada elemento dentro de la suma total de 12 columnas.

5. Componentes Reutilizables

Son elementos modulares de interfaz prediseñados (botones, tarjetas, barras de navegación, modales y alertas) creados bajo estándares de accesibilidad WAI-ARIA. Su uso evita reescribir código y asegura que todos los módulos compartan el mismo comportamiento funcional.
