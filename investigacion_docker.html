Investigacion sobre Docker

Contenedores para desarrollar, distribuir y ejecutar aplicaciones

1. Que es Docker?

Docker es una plataforma de codigo abierto que permite empaquetar una aplicacion junto con sus dependencias dentro de un contenedor. De esta forma, el software puede ejecutarse de manera consistente en distintos equipos y ambientes.

Objetivo principal: evitar diferencias entre el ambiente de desarrollo, pruebas y produccion.

2. Ventajas de utilizar Docker

  • Portabilidad: una imagen puede ejecutarse en cualquier sistema compatible.
  • Aislamiento: cada aplicacion mantiene sus dependencias separadas.
  • Rapidez: los contenedores se inician en pocos segundos.
  • Eficiencia: usan menos recursos que una maquina virtual tradicional.

3. Imagenes y contenedores

Una imagen es una plantilla inmutable que contiene el codigo, las librerias y la configuracion de una aplicacion. Un contenedor es una instancia en ejecucion de esa imagen. Varias instancias pueden utilizar la misma imagen sin modificarla.

Imagen: plantilla Contenedor: proceso Registry: almacenamiento

4. Dockerfile

Un Dockerfile es un archivo de texto con instrucciones para construir una imagen. Cada instruccion puede generar una capa reutilizable, lo que ayuda a acelerar futuras construcciones. 

FROM nginx:alpine
COPY . /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

5. Comandos esenciales

Comando Funcion
docker buildConstruye una imagen.
docker runCrea e inicia un contenedor.
docker psMuestra contenedores activos.
docker stopDetiene un contenedor.

6. Docker Compose

Docker Compose permite definir y ejecutar aplicaciones formadas por varios servicios mediante un archivo YAML. Es util para coordinar una aplicacion web, una base de datos y otros servicios relacionados con un solo comando.
