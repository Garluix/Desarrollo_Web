Investigación de Comandos Docker

Referencia técnica, sintaxis, ejemplos y casos de uso en el ciclo de vida de contenedores

docker --version
Uso Principal:

Consultar la versión de Docker instalada en el sistema local.

Sintaxis General docker --version
Ejemplo de Uso docker --version
Resultado / Caso de Uso

Docker version 29.7.2. Se utiliza como comprobación inicial post-instalación para verificar que el cliente CLI de Docker está operativo.

docker run hello-world
Uso Principal:

Ejecutar una imagen oficial de prueba para validar el motor.

Sintaxis General docker run hello-world
Ejemplo de Uso docker run hello-world
Resultado / Caso de Uso

Descarga la imagen del Hub, la ejecuta mostrando un mensaje de bienvenida y finaliza. Valida que el demonio de Docker puede descargar y correr contenedores.

docker images
Uso Principal:

Listar las imágenes locales almacenadas en el equipo.

Sintaxis General docker images [OPCIONES] [REPOSITORIO[:TAG]]
Ejemplo de Uso docker images -a
Resultado / Caso de Uso

Muestra una tabla con Repositorio, Tag, Image ID, Fecha de creación y Tamaño. Se usa para auditar imágenes disponibles y obtener IDs para ejecución o borrado.

docker ps
Uso Principal:

Mostrar los contenedores que se encuentran activos.

Sintaxis General docker ps [OPCIONES]
Ejemplo de Uso docker ps
Resultado / Caso de Uso

Lista los contenedores con estado "Up", puertos expuestos y nombres asignados. Permite comprobar en tiempo real si el servidor web de la aplicación está activo.

docker ps -a
Uso Principal:

Mostrar todos los contenedores (activos, pausados y detenidos).

Sintaxis General docker ps -a
Ejemplo de Uso docker ps -a
Resultado / Caso de Uso

Presenta el historial completo de contenedores. Indispensable para diagnosticar contenedores que se cerraron con errores o recuperar IDs para reiniciarlos.

docker build
Uso Principal:

Construir una nueva imagen personalizada desde un archivo Dockerfile.

Sintaxis General docker build [OPCIONES] RUTA_CONTEXTO
Ejemplo de Uso docker build -t app-six-seven:v1 .
Resultado / Caso de Uso

Ejecuta secuencialmente las directivas del Dockerfile en el directorio actual (.) y etiqueta la imagen lista para ser desplegada.

docker run
Uso Principal:

Crear y poner en ejecución un contenedor a partir de una imagen.

Sintaxis General docker run [OPCIONES] IMAGEN [COMANDO]
Ejemplo de Uso docker run -d -p 8080:80 --name web-equipo app-six-seven:v1
Resultado / Caso de Uso

Inicia el contenedor en segundo plano (-d) vinculando el puerto 8080 local al 80 del servidor web para poder abrir el sitio desde el navegador.

docker stop
Uso Principal:

Detener la ejecución de uno o más contenedores de forma ordenada.

Sintaxis General docker stop [OPCIONES] CONTENEDOR [CONTENEDOR...]
Ejemplo de Uso docker stop web-equipo
Resultado / Caso de Uso

Envía la señal SIGTERM para que los procesos internos guarden estado y cierren conexiones antes del apagado seguro.

docker start
Uso Principal:

Reanudar la ejecución de un contenedor previamente detenido.

Sintaxis General docker start [OPCIONES] CONTENEDOR
Ejemplo de Uso docker start web-equipo
Resultado / Caso de Uso

Reactiva el contenedor conservando sus datos, mapeo de puertos y configuraciones originales sin necesidad de crearlo de nuevo.

docker rm
Uso Principal:

Eliminar definitivamente uno o más contenedores del sistema.

Sintaxis General docker rm [OPCIONES] CONTENEDOR
Ejemplo de Uso docker rm -f web-equipo
Resultado / Caso de Uso

Elimina el contenedor. Si está en ejecución se usa la bandera de forzado (-f). Se usa para limpieza de recursos y liberación de nombres de contenedores.

docker rmi
Uso Principal:

Eliminar una o más imágenes almacenadas localmente.

Sintaxis General docker rmi [OPCIONES] IMAGEN [IMAGEN...]
Ejemplo de Uso docker rmi app-six-seven:v1
Resultado / Caso de Uso

Borra la imagen del disco duro siempre que no haya contenedores dependientes de ella. Esencial para liberar almacenamiento en disco.

docker logs
Uso Principal:

Consultar la salida estándar y registros generados por un contenedor.

Sintaxis General docker logs [OPCIONES] CONTENEDOR
Ejemplo de Uso docker logs -f --tail 50 web-equipo
Resultado / Caso de Uso

Muestra los mensajes de consola y errores de la aplicación en tiempo real (-f). Utilizado en depuración técnica cuando un servicio no responde.

docker exec
Uso Principal:

Ejecutar un nuevo comando dentro de un contenedor que está corriendo.

Sintaxis General docker exec [OPCIONES] CONTENEDOR COMANDO [ARG...]
Ejemplo de Uso docker exec -it web-equipo sh
Resultado / Caso de Uso

Abre una sesión interactiva (-it) dentro del contenedor para verificar archivos, configuraciones o conectividad de red interna.
